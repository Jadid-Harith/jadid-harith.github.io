Privacy Policy

Effective 10 November 2026

This policy explains what Ember Station ("the app"), operated by Jadid Harith ("the operator"), does with data from the platforms it connects to: YouTube (Google), TikTok and Instagram (Meta).

Who uses the app

The app is a private tool. It connects only to social media accounts owned by the operator. It does not collect data from the general public and has no other users.

What data the app accesses

  • Account basics: the connected account's ID and username or channel name, used to make sure each clip goes to the right account.
  • Publishing permission: permission to upload videos and post them, with the caption and settings the operator approved.
  • Published post details: the link and ID of each published post, and later its public view counts, so the operator can track results.

The app does not read private messages, followers' personal data, contacts, or any content the operator did not create or approve.

How the data is used

Only to publish the operator's own approved videos and to keep a record of what was published. The data is never sold, rented, shared with advertisers, or used to build profiles of anyone.

Where the data is stored

Access tokens are stored on the operator's own computer and are used only to call the platforms' official APIs. Records of published clips (title, caption, link, view counts) are kept in the operator's private dashboard. Video files are deleted after publishing, and preview copies are removed within a few days.

How long it is kept

Records are kept while the operator uses the app. Tokens are deleted when the operator disconnects an account or stops using the app.

Your controls

Access can be revoked at any time from each platform's settings: Google Account → Security → Third-party access; TikTok → Settings → Security → Manage app permissions; Instagram → Settings → Apps and websites. To request deletion of any stored data, email jadidharith@gmail.com.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
